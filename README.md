# SQL Assignment 1 – DDL Commands and Constraints

## Project Overview
This assignment demonstrates the use of SQL Data Definition Language (DDL) commands and database constraints using MySQL.

## Part 1: DDL Commands
- CREATE DATABASE and CREATE TABLE
- ALTER TABLE – ADD, MODIFY and DROP columns
- RENAME COLUMN and RENAME TABLE
- TRUNCATE TABLE
- DROP TABLE and DROP DATABASE

## Part 2: Constraints
Created three tables:
- Departments
- Location
- Employees

Implemented the following constraints:
- PRIMARY KEY
- NOT NULL
- UNIQUE
- ENUM
- CHECK
- DEFAULT
- FOREIGN KEY
- AUTO_INCREMENT

## Sample Data
Inserted sample records into the Departments, Location and Employees tables to test the database relationships and constraints.

## Tools Used
- MySQL
- MySQL Workbench
- GitHub

## Learning Outcome
Gained practical experience in creating and modifying database structures, implementing constraints, managing table relationships and executing SQL queries.
